## 🚀 Getting Started

### Prerequisites

- Node.js 18+ (or Python 3.8+ for Python projects)
- npm or yarn
- PostgreSQL 14+


### Installation

```bash
# Clone the repository
git clone https://github.com/magzumAlmat/logisticBack.git

# Navigate to the project
cd logisticBack

# Install dependencies
npm install

# Set up environment variables
cp .env.example .env
# Edit .env with your configuration

# Run the application
npm start
```
